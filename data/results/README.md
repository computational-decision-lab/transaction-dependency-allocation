# Compact result files

`baseline/` contains the 800-fixture analysis summaries and the captured baseline RPC transcript. `extensions/` contains the independent reconstruction and mutation checks for the 780-fixture extension. `v30_comparison/` contains the v30.2 comparison verification and interpretation. The full signed fixtures and larger captures are outside GitHub; see the repository-level `REPRODUCIBILITY.md` and the separate large-data archive.

The JSON reports are machine-readable outputs of the independent audit and solver checks. They are evidence about the declared Regtest inputs and policies, not Mainnet measurements.
